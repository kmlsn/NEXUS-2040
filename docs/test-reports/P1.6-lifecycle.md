| Yolculuk/invariant | Kanıt | Sonuç |

| Worker health | Ayrı worker sürecinde `GET /health` → `200`, `service=worker`, `Cache-Control: no-store` | `PASS` |
| Güvenli request ID | Geçerli `safe_test_01` API yanıtında korunur; 65 karakterlik geçersiz değer sunucunun ürettiği 36 karakterlik UUID ile değiştirilir. | `PASS` |
