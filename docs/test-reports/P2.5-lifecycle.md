|---|---:|---|
| `pnpm services:up; pnpm services:check; pnpm --filter @nexus/api run test:integration` | 0 | Yerel servis sağlığı ile migration, kuyruk/maliyet/iade, finish uzlaşması, ledger idempotency ve concurrency entegrasyon yolları geçti. |
| `pnpm --filter @nexus/api run test:migrations` | 1 | Böyle bir package script'i yoktur; önceki `test:integration` komutu migration entegrasyonunu zaten çalıştırıp geçti. Bu test-runner komut hatası ürün hatası değildir. |
| `<stdin> | pnpm exec tsx -` (API çalışma dizininde disposable P2.5 PostgreSQL probe) | 0 | Bu rapordaki yeni profil, kalıcılık/retry, tek şerit, iptal/iade, finish sınırı, recovery ve L1→L2 üretim yolculuklarını bağımsız olarak çalıştırdı; disposable veritabanını sildi. |
| `pnpm --filter @nexus/api run typecheck; pnpm --filter @nexus/simulation run test; pnpm run verify; pnpm services:down` | 0 | API typecheck, ilgili simülasyon regresyonları, kök doğrulama ve servis kapatma geçti. `test:e2e`, mevcut fazda kullanıcı arayüzü oyuncu akışı olmadığı için kök komutta açıkça `DEFERRED` raporlandı. |
